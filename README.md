# The Unfinished Way · 个人数学网站

Blue Archive 风格的个人数学档案站（占位骨架阶段）。

## 常用命令

| 操作 | 命令 | 说明 |
|------|------|------|
| 本机预览 | `npm run dev` | 浏览器打开 http://localhost:4321 |
| 正式构建检查 | `npm run build` | 生成 dist/ 静态文件 |
| 预览构建结果 | `npm run preview` | 本机查看 build 结果 |

首次使用先安装依赖：`npm install`

## 目录速览

- `src/pages/` — 所有页面（路由 = 文件夹路径）
- `src/components/` — 页面部件（导航、卡片等）
- `src/data/` — 内容条目数据（占位，后续换成内容集合）
- `src/styles/global.css` — 全站样式与配色变量
